# Python asyncio overview

asyncio is a library for writing concurrent code using the async/await syntax. It is built around an event loop that schedules coroutines. A coroutine is defined with async def and only runs when it is awaited or scheduled as a task. Because the event loop runs on a single thread, asyncio is best for I/O-bound work such as network requests, where tasks spend most of their time waiting. For CPU-bound work, use multiprocessing instead, because the global interpreter lock prevents threads from running Python bytecode in parallel. The function asyncio.gather runs several awaitables concurrently and returns their results in order. Use asyncio.create_task to start a coroutine in the background without waiting for it immediately. Timeouts can be applied with asyncio.wait_for, which raises TimeoutError if the awaitable takes too long.
