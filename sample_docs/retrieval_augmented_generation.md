# Retrieval-augmented generation

Retrieval-augmented generation, or RAG, combines a search step with a language model. Documents are split into chunks, converted to embeddings, and stored in a vector database. At question time the query is embedded and the most similar chunks are retrieved. These chunks are placed in the prompt so the model can answer from supplied evidence instead of relying only on its training data. This reduces hallucination and lets the system cite sources. Chunk size matters: very small chunks lose context, while very large chunks dilute relevance and waste prompt space. Overlap between neighbouring chunks protects answers that span a boundary. Common evaluation metrics for the retrieval stage are hit rate at k, which checks whether a relevant chunk appears in the top k results, and mean reciprocal rank, which rewards placing the relevant chunk higher.
